Программа хранит base64 представление бинарной строки, представляющей файл шаблона отчёта.
Файл шаблона соделжит офрмление и плейсхолдеры в стиле jinja ( {{ param }} ... )

Утилита "gen_str_data.py" ожидает что в текущей директории находится файл шаблона "template.docx"
Запуск утилиты без параметров сохранит бинарное содержимое файла шаблона в строку вида 
"TEMPLATE_BASE64_STRING = ....base64...."  в файл "template_docx.py"

Далее файл "template_docx.py" требуется скопировать в корневую директорию Программы.
